Where each part of CodeBridge stands. For a shorter overview, see the [README](../README.md).

means it is partly implemented or not validated end to end.

## Extension host services

The plugin stands in for the VS Code workbench: extensions call `MainThread*` services expecting an
editor on the other end. Anything unanswered is a hole an extension can fall into, whatever the state
of language support.

87 services in the pinned runtime (VSCodium 1.143.17183), read from the running bundle rather than a
checked-in list. **16 implemented, 20 partial, 1 stubbed, 50 not supported.** See
[workbench coverage](workbench-coverage.md) for details and for the separate question of which
language-feature providers are drawn.

Answering a service is not the same as drawing its features. `MainThreadLanguageFeatures` records
that an extension has a provider; each feature then needs a `$provide*` call and a translation into
an IntelliJ feature. Of 65 non-AI provider registrations the runtime exposes, 28 are drawn: hover,
debugger hover expressions, completion, inline completion, signature help, definition, type
definition, implementation, references, rename, document highlights, semantic tokens (whole document
and range), code actions, document, range and on-type formatting, inlay hints, code lenses, workspace
symbols, document symbols, folding, call and type hierarchies, selection ranges, document links,
linked editing and document colours. Diagnostics arrive by push.
